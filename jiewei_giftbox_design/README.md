# 解围——邯宝坊六味邯郸机关礼盒概念提案

赛道一包装设计候选方案。以“围魏救赵”的先侧移、后中央显现为结构逻辑，输出参数化 CAD、三状态 STEP、刀模、渲染与 6 张 A4 展板。

本目录中的六个 `68 × 62 × 44 mm` 内装均为原创概念二次包装模块，分别对应鸡泽辣椒、魏县鸭梨、涉县核桃、武安小米、永年大蒜和大名小磨香油六类邯郸地域产品。方案未使用现售商品图、商标、条码、许可证或法定食品信息，不代表已获品牌联名授权。参赛者完成实名、签字和官方报名表后，可以“概念提案”口径提交。

## 目录

- `01_research/`：事实来源与字体许可
- `02_identity/`：字标、双节外套与六个概念产品标签
- `03_cad/`：FreeCAD、STEP、STL 与刀模
- `04_renders/`：三状态、爆炸图和双节 CMF 渲染
- `05_boards/`：6 张 A4 展板的 SVG/JPG/PDF
- `06_submission/`：作品说明、估价、概念品类证据表和来源清单；历史品牌协作申请材料仅供后续扩展，不进入当前投稿包
- `07_audit/`：技术审计与人工视觉复核
