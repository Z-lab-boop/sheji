## 目录说明

- `competition_brief.md`：比赛硬性要求、邮箱、截止时间与知识产权边界。
- `submission_readiness.md`：逐件作品的完成度、阻塞项和行动顺序。
- `build_hanbaofang_authorization_packet.py`：生成《解围》商品资料与参赛授权申请书；空白签章页不代表已授权。
- `claim_evidence_ledger.csv`：所有关键主张与证据、可用表述、禁用表述。
- `rubric_matrix.csv`：按赛事命题推导的非官方评审覆盖矩阵。
- `form_fill_text.md`：可复制到官方报名表的 200 字以内作品说明。
- `route_verification_2026-10-02.md`：《步步生典》四个文化节点的最新公开来源复核。
- `email_templates.md`：投稿邮箱、主题、正文与附件清单；不代表已发送。
- `forms/`：官网下载的空白报名表与汇总表，未填写任何个人信息。
- `build_submission_packages.py`：复核图片参数并生成候选附件目录、ZIP、哈希和 JSON 审计报告。
- `packages/`：脚本生成的候选附件包；名称中的“待填写”或“禁止直接投稿”是状态提示。

## 生成与复核

```bash
python3 competition_submission/build_submission_packages.py
python3 competition_submission/build_final_handoff.py
```

第一条命令检查三件作品的数量、像素尺寸、RGB、300 dpi、JPG 和单张不超过 5 MB，并生成各自候选包与 SHA-256 清单。第二条命令汇总投稿包、三套 CAD/模型包和说明书；CAD 备查材料不作为初审邮件附件。

## 正式投稿前必须由参赛者完成

1. 在官方报名表填写真实姓名、身份证号、手机、邮箱、院校/单位、指导教师（如有）和作品信息。
2. 电子签名后，同时保存 Word 版和 PDF 版。
3. 确认作者顺序；团队作品最多 5 人。
4. 用规定主题发送邮件；未经参赛者明确授权，本仓库不会代发邮件。
5. 保留 SVG、FCStd、STEP、STL 等源文件，以备获奖后提交。
