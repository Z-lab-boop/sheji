# 步步生典——邯郸双节漫游章匣

2026“和氏璧杯”赛道二候选作品。项目以参数化 CAD 为产品几何唯一来源，建立城市漫游章匣、六枚模块章、折叠路线图、渲染、A4 展板与投稿审计。

## 项目边界

- 中秋与国庆是使用场景，不替代邯郸成语文化主线。
- 路线图属于文化路线示意，不是测绘或实时导航产品。
- 景点开放状态、名称和路线在正式投稿前必须人工复核。
- 数字模型与本地审计不等于实体样机测试或正式投稿。

## 目录

- `01_research/`：来源、字体与许可。
- `02_identity/`：字标、章面与地图矢量。
- `03_cad/`：FreeCAD 源文件、STEP、STL 与结构说明。
- `04_renders/`：CAD 驱动渲染。
- `05_boards/`：8 张 A4 展板源文件与导出稿。
- `06_submission/`：报名表可粘贴文本与来源清单。
- `07_audit/`：技术审计与人工复核记录。
